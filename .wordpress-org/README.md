# WordPress.org listing assets

Copy the PNG files in this directory to the WordPress.org SVN repository's top-level `assets/`, alongside `trunk/` and `tags/`. Do not copy this README or place listing assets inside the runtime plugin ZIP. GitHub itself is not a WordPress.org requirement.

- Banners: banner-772x250.png and banner-1544x500.png (standard and Retina).
- Icons: icon-128x128.png and icon-256x256.png, from the existing Picsart brand assets.
- Screenshots: screenshot-1.png through screenshot-7.png correspond to the seven readme.txt captions. These are the owner's unchanged October 5 interim captures, including the visible account details, and are not fresh acceptance evidence. Displayed models, balances and prices are examples from the capture date.
- Banner: AI-assisted artwork using the existing Picsart banner as the brand reference, prepared October 6, 2026. It does not promise prices or plan entitlements.
