# Security reporting

Do not report exploitable vulnerabilities, tokens, private media, or account details in public GitHub issues.

Use GitHub's private **Report a vulnerability** action if it is enabled for this repository. Otherwise contact [Picsart Support](https://support.picsart.com/hc/en-us/requests/new), identify `PicsArt/wp-woo-plugin`, and request private security escalation. Do not attach credentials; arrange secure follow-up for sensitive evidence.

Include the affected plugin version/commit, WordPress/PHP/WooCommerce versions, reproduction steps on a disposable site, expected and actual behavior, and potential impact. Redact authorization headers and personal data. Do not test against another person's store or spend their credits.

This is a pre-publication source snapshot; no separate supported-version schedule or response-time guarantee is established here. Maintainers should verify and document supported releases when public distribution begins. An account connection or separately hosted service issue may require coordinated remediation outside this repository.
